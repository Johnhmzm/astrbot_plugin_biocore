## 为什么先做评价矩阵

```
样本效率   每轮给出 7 个方程，100 轮即可接近真值下界（实测 RMSE 0.0117 vs 下界 0.0106）
影响面     决定「被骂伤到信任还是自尊」，是性格层，不是强度层
前置条件   需要每轮记下 dims、outs、状态前后值（约 20 行）
```

## 顺序

1  评价矩阵    上电完成，补日志后即可拟合

3  关系层      用 relationship 快照估更新率
4  CAPS        需要足够多的饱和样本，长期观察
