## 一、AstrBot（主线）

### A1 内核落后一整代
- 证据：部署的 `pipeline.py` 198,075 字节；仓库 wip 367,165 字节
- 证据：`biocore_memory` 部署 87 个 py / 437KB；仓库 109 个 py / 745KB
- 差异：22 个文件，全在 `event/*`（activation/chains/claims/compaction/events）与 `space_learning`
- 后果：**那侧没有事件层**，所以承诺、待办、未答永远不会出现
- 决定：回灌，但不整包替换——一次一个模块

### A2 八点主动消息
- 现状：`main.py` `AUTONOMY_QUIET_START_HOUR=0`、`AUTONOMY_QUIET_END_HOUR=8`（硬编码）
- 另有一处旧默认 `quiet_start=23, quiet_end=8`（第 4628 行）与之不一致
- 现象：静默一解除，第一个 tick 就把攒了一夜的条件放出来
- 要做：静默时段配置化；两处默认值统一

### A3 学习没有接线
- 有：`policy_learning.make_context(silence_phase, attachment, hour)`，奖励含 `responded`
- 缺：`should_send` 不读 `policy_q`
- 后果：学会了「8 点没人回」也进不了「8 点要不要发」
- 要做：发送前加一道闸——该小时历史回复率低且样本够 → 不发
- 注意：别用 Q 表做这件事，样本要求太高（32 个上下文覆盖 24 小时）

### A4 WAL 未合并
- 证据：`memory.sqlite3` 7.2 MB，`-wal` 5.3 MB
- 风险：备份易漏；长期写入变慢
- 要做：定时 checkpoint，或备份前强制 checkpoint

### A5 记忆存什么
- 证据：AstrBot `entries` 274 条 / 4 个 session_docs
- 证据：DSH 单会话 506 条，其中大量是助手自己的长回复
- 待定：助手回复要不要进记忆；进的话是否只留摘要

## 五、设计结论（2026-11-09 讨论产出）

### C1 类型通道：类型不能被压成强度
- 实验：`probe_same_numbers.py` —— 同一组 dims，「承诺被违背」与「被威胁」十步后轨迹**完全相同**
- 结论：`appraise()` 只吃 7 个 dims、吐 7 个 outputs，全程没有承载「是哪一种事」的通道
- 方向：不枚举类型表（不通用），改为「语义向量 + 固定投影」——含义以**方向**进入，而非强度

### C2 人设作为度规（待实现）
- 实验：`probe_persona_metric.py` —— 人设为各维权重时，「被忽视」在两种人设下方向余弦 0.816（非缩放）
- 现状缺口：`bio-persona-inject` 注入 traits/baseline/drives/learning_rate，**只改反应幅度，不改「什么被在意」**
- 要做：编译产物增加一份权重（作用于 dims → 状态的映射），与基线并列，可解释、可回退
- 判据：同一事件、不同人设，状态增量方向必须不同（余弦 < 0.9）；若只缩放（余弦 ≈ 1）视为未生效

### C3 空间化
- 结论：7 维是人挑的基，装不下抽象概念
- 方案：本体用 32–128 维连续空间（模型每轮注入向量），核心只做动力学（衰减/惯性/耦合）
- 保留少量可解释轴作为**视图**，只用于展示与调试
- 待定：空间维度取 64 还是更低；「她」是空间的初始点还是轨迹

### C4 学习应下沉到高频层
- 实验：`probe_learned_gate.py`（v1 失败：学习取代静默，回复率 44.4% → 26.7%）、`probe_learned_gate_v2.py`（静默保留，44.4% → 46.7%）
- 结论一：**学习层只能叠加在硬约束之上，不能取代它**
- 结论二：每天 3 条上限 → 每小时样本不足 4 条，低频决策学不动
- 方向：学习目标从「几点发」下沉到「怎么说」（长度/提问/引用/语气），样本量每轮都有
- 实验：`probe_learn_how.py` —— 高频层能学（+12%），但暴露两个缺陷：未按情境分桶、探索过早枯竭
- 待定：奖励信号从哪来。候选：模型反向注入的维度化自评（需校准），而非「回复长度」这类代理
