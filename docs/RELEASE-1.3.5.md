# BioCore 1.3.5（beta）发布说明

## 变更摘要
- 设置页重构为 6 标签：API / 生物 / 记忆 / 模型 / 球体 / 系统；简单/高级视图；11 个功能开关（旧键自动映射）。
- 自主行为：设置页可调总开关、发送开关、阈值、最大字数；状态接 status.autonomy；仅私聊生效。
- 人格：编译用人设下拉、当前人设显示、双击内完成编译；人设不再显示 default 占位。
- LLM：收敛为图片描述 + 归档批量 2 个开关 + 全局路由 + 今日预算；归档改后台批量（≥5 条/≥10 分钟/会话结束，每批 1 次调用）。
- 单次调用协议：行为规则写进提示词 + `<bc>` 标签反注；旁路 LLM 默认关（[实验]）。
- 泄漏兜底：协议回显剥离 + leak_guard 指标。
- 构建守卫与 UI 兼容层（schema=2、旧键迁移）。

## 升级注意
1. 旧配置会自动迁移：localStorage schema=2、旧开关 → 新功能开关（只迁移开状态），旧键保留不删除。
2. 已用 primary 的用户：升级前确认 core store 内已有数据（/data 下 store 文件存在且 entries>0），否则先切回 shadow 验证一次。
3. 旧「每轮增强」「修复策略」「事件总结」等开关已并入规则/批量，不会单独调用 LLM（默认每轮额外调用 0 次）。
4. 首次打开面板会构建内联产物（index.html），如旧缓存异常请强刷。

## 回退方式
- 面板：核心状态 → 模式按钮「回退」一键降级到 shadow/off（不丢数据）。
- 整包：使用升级前备份 zip（scripts/backup 目录产物）覆盖插件目录，配置与 data/ 保留。
- 如遇渲染空白：先执行 `node scripts/guard.mjs` 定位；旧产物可从 data/_backup 恢复 index.html。
