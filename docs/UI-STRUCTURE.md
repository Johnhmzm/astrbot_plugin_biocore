# UI 结构方案（B：重做页面结构，保留视觉语言）

目标：把「调试面板」变成「看得懂的伴侣状态页」。
原则：一眼 / 扫一眼 / 深挖 三层；人类语言优先；原始数值折叠。

## 一、导航（左栏）

```
情绪概览   ← 球体 + 情绪（保留现有）
她现在     ← 新：想不想找你、心情、身体
关系       ← 新：阶段、信任、互动记录
记录       ← 新：她发过什么、你回没回
设置       ← 保留，但配置项收敛

[高级]     ← 折叠入口：表达意图 / 内部参考 / 原始数据
```

原「表达意图」6 个子标签 → 收进「高级」：
```
保留：当前意图、内部参考
移入高级：自主行为(改为只读)、表达流程、她的感受、想怎么回应
```

## 二、页面结构

### 1) 她现在（新主页，最重要）

```
┌────────────────────────────────────────────┐
│  她现在想找你                    73%        │
│  ██████████████████████████░░░░░░░          │
│  等了你 3.2 小时 · 有点急                    │
├──────────────┬──────────────┬──────────────┤
│ 想你的理由    │ 她的身体      │ 她的心情      │
│ 很久没联系    │ 精力 0.72    │ 开心 · 靠近   │
│ 记得明天体检  │ 欠 1.2h 睡眠 │ 心情偏低回升  │
│ 上次话题未了  │ 节律：清醒    │ 自尊 0.51     │
├──────────────┴──────────────┴──────────────┤
│  她刚才在想什么                              │
│  「是不是我上次话说重了」                     │
├────────────────────────────────────────────┤
│  [测试触发一次]  [立即评估]                  │
├────────────────────────────────────────────┤
│  ▸ 详细数据（折叠）                          │
└────────────────────────────────────────────┘
```

数据映射：
```
73%            → V / theta
等了你 3.2 小时 → silence.hours + phase 中文
想你的理由      → autonomy_reason 主因 + 情绪 top3 + memory_due
她的身体        → energy / sleep_debt / circadian
她的心情        → labels + mood.label + self_esteem
她刚才在想什么  → rumination.text（若有）
```

### 4) 设置（配置项从 8 → 5）

```
┌────────────────────────────────────────────┐
│  [√] 允许她主动找你                          │
│                                            │
│  她有多黏   ○ 克制  ● 正常  ○ 黏人           │
│            （黏人 = 抽离期也不放弃）          │
│                                            │
│  她有多敏感  ○ 迟钝  ● 正常  ○ 敏感          │
│                                            │
│  每天最多    [ 5 ] 条（每小时自动 2 条）      │
│  想你的阈值  [======●=====] 0.55            │
│                                            │
│  ▸ 高级（依恋风格 / 字数上限 / 静默时段）     │
└────────────────────────────────────────────┘
```

映射：
```
她有多黏   → autonomy_clingy（克制=false, 正常=true, 黏人=true+间隔更短）
她有多敏感 → rejection_sensitivity（0.2 / 0.4 / 0.7）
每天最多   → daily_cap（小时自动 ceil/3）
阈值       → theta
```

## 三、信息层级规则

```
L1 一眼：1 个数字 + 1 句话
L2 扫一眼：3 张卡，每张 ≤3 行
L3 深挖：折叠区，原始数值 + 字段名 + 时间戳
```

**默认不显示**：drive_mult、phase_weight、frust_mult 这类工程参数 → 全部 L3。

## 四、保留的视觉语言

```
细条 2-4px（.bar）
橙色强调 --accent
等宽小标签（mono）
卡片直角 + 1px 边框
不使用圆角大卡片 / 阴影 / 渐变背景
```

## 五、实施顺序

```
1. 导航重排 + 「高级」折叠入口（不动页面内容）
2. 「她现在」新页（数据全部已有，只做展示）
3. 「关系」新页
4. 「记录」新页（读 loop/bid 数据）
5. 设置页收敛为 5 项
6. 原「表达意图」6 标签收进高级
```
