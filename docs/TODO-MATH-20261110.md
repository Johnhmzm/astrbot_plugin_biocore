# 数学改造清单（2026-11-10）

把模型训练里那套可迁移的数学，逐条落到生物层。每条都写清：目的、落点、验收、成本。
不增加模型调用是硬约束——这些都只动数值与算法。

## 一、θ 更新：动量 + 自适应步长（Adam 的影子）

**目的**：现在每步固定 ±5%，小样本下极易过冲。动量记住方向，自适应按各参数历史方差缩放步长。

```
落点  biocore_runtime/theta.py: iterate()
做法  m ← β1·m + (1-β1)·g ；v ← β2·v + (1-β2)·g² ；θ ← θ - lr·m̂/(√v̂+ε)
      g 由「参数与评分的相关方向 × 验证增益」给出（无梯度，用有限差分符号代替）
      lr 初值 0.01，β1=0.9，β2=0.999
验收  合成数据（真关系）收敛更快且不过冲；噪声数据仍拒绝；回滚仍有效
成本  零模型调用；改动约 40 行
```

## 二、状态归一化（LayerNorm 的思路）

**目的**：现在给模型的是裸值（效价 -0.15），跨用户不可比。归一化后给「相对你自己平常偏低 0.4σ」。

```
落点  pipeline.py: _state_block()
做法  为每维维护滑动均值 μ 与标准差 σ（EMA，α=0.05）；渲染时输出 z=(x-μ)/σ
      同时保留裸值一行，便于对照与调试
验收  同一段对话在不同基线的两个会话里，z 值接近、裸值不同
成本  零额外调用；需持久化 μ/σ（随会话存）
```

## 三、检索加权：softmax 温度（注意力的影子）

**目的**：现在是余弦硬排序，等价温度→0，模型永远只拿到最相似那几条。给一个可调温度，让候选有权重。

```
落点  pipeline.py: _sentence_recall_block()
做法  w_i = exp(s_i / T) / Σ exp(s_j / T)；T 初值 0.05，可在配置里调
      装块顺序仍按 w 降序，但允许「次优但多样」的句子进入
验收  同问题同预算下，块内句子多样性上升，锚点级召回不降（对照 170 题）
成本  零模型调用；改动约 25 行
```

## 四、基线：EMA 时间常数可学

**目的**：现在 anchor_relax、replay_learn 是手设常数。它们本质是时间常数 τ，应从数据里定。

```
落点  mindbase_bridge.py: ANCHOR_RELAX / REPLAY_LEARN
做法  把两者作为 θ 的两个维度纳入参数循环（已在 BOUNDS 里），并允许缩放律估计其所需样本数
验收  在真实日志上跑 200 轮后，参数是否稳定（不自激、不发散）
成本  依赖日志积累；无额外调用
```

## 五、信息量：每轮状态移动量（KL 的影子）

**目的**：现在无法回答「这句话对她影响多大」。用状态分布的前后差做指标。

```
落点  turn_end 后记录 delta_kl = KL(p_after || p_before)
做法  把五维状态视作高斯（对角），KL 有闭式解；记录到 turn_log.jsonl
验收  问候类语句 KL 小、被骂类 KL 大；可用于筛选「有影响力」的样本做训练
成本  零调用；约 20 行
```

## 六、稳态：PI 控制器（带抗积分饱和）

**目的**：现在回拉是固定系数，遇到持续刺激会滞后或过冲。写成控制器更可控。

```
落点  mindbase_bridge.py: _tick_once()
做法  u = Kp·e + Ki·∫e（e = 基线 - 当前值），积分项设上限（anti-windup）
验收  阶跃扰动下回到基线的时间可预测；不出现持续振荡
成本  零调用；约 30 行
```

## 七、缩放律：每个参数需要多少样本

**目的**：现在是凭感觉。先算一个下界，决定「先攒数据」还是「先调参」。

```
落点  离线脚本：用现有 turn_log 估计各参数的信噪比，反推所需样本量
做法  对每个参数拟合 y = a + b·x + ε，用 b/σ_ε 估所需 n（给定功效 0.8）
验收  产出一张表：参数 → 当前样本数 → 达标所需样本数
成本  零调用；一次性脚本
```

## 顺序与依赖

```
先  五（信息量）    没有它，其余都没法评估影响大小
再  二（归一化）    影响模型读到什么，可立即验证
再  三（softmax）   影响检索，可用 170 题对照
再  六（PI）        影响稳定性，需要长跑
再  一（动量）      依赖更多日志
后  四（τ 可学）    依赖一与七
后  七（缩放律）    结论可能否定四，先算再花时间
```

## 明确不做

```
不训练替代模型        样本不足，且会让状态失去可解释性
不拆预训练权重        权重里没有情绪动力学
不引入本地大模型      破坏「零本地模型」的通用性约束
```
